## Objetivo del portafolio
Integrar en un solo repositorio las prácticas realizadas durante la materia, mostrando la evolución desde programas básicos de consola hasta proyectos con interfaz gráfica, programación orientada a objetos, manejo de archivos, estructuras dinámicas y conexión a base de datos.
## Cómo ejecutar el index general
El archivo principal del portafolio es [`Index.java`](./Index.java). Este programa abre una interfaz gráfica con un botón **Ejecutar proyecto** para cada práctica y una descripción debajo de cada botón.
```bash
javac Index.java
java Index
```

## Aprendizajes principales
- Estructura básica de un programa en Java y uso del método `main`.
- Entrada y salida de datos por consola.
- Condicionales, ciclos, menús y validaciones.
- Programación orientada a objetos: clases, objetos, métodos, encapsulamiento y herencia.
- Uso de arreglos, matrices y `ArrayList`.
- Creación de interfaces gráficas con Swing.
- Lectura y escritura de archivos de texto.
- Organización de proyectos con Maven/Ant.
- Modelo MVC, DAO y conexión a bases de datos MySQL.
